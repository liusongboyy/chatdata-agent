## Agent skills

### Issue tracker

Issues 和 specs 作为 markdown 文件存放在 `.scratch/<feature>/` 下（**不提交**，见 `.gitignore`）。
长期有价值的设计文档同步到 [chatdata-agent-design](https://github.com/liusongboyy/chatdata-agent-design)。
见 `docs/agents/issue-tracker.md`。

### Triage labels

五个 canonical triage roles，label 字符串与 role 名一致。见 `docs/agents/triage-labels.md`。

### Domain docs

Single-context：repo 根目录一个 `GLOSSARY.md` 加 `docs/adr/`。见 `docs/agents/domain.md`。
